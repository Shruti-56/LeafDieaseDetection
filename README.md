# 🍃 Leaf Disease Detection App

A smart Android application that helps farmers and gardeners **detect leaf diseases** by simply capturing or uploading an image of a leaf. The app uses machine learning to identify the disease and suggests possible treatments.

---

## 🧠 Features

- 📷 **Scan or Upload Leaf Images**
- 🤖 **Automatic Disease Detection** using ML model
- 💊 **Treatment Suggestions** for each disease
- 🧾 User-friendly interface and easy navigation
- 🌐 Works offline after model is downloaded



## 🚀 How It Works

1. **User takes a photo** or selects a leaf image from gallery.
2. **Image is processed** by a trained Machine Learning model.
3. The app **predicts the disease**, if any.
4. The user receives:
   - **Disease name**
   - **Detailed description**
   - **Suggested treatment options**

---

## 🛠 Tech Stack

- **Android (Java)**
- **TensorFlow Lite** for on-device ML
- **XML** for UI design
- **SQLite/MySQL** (optional for treatment data)
